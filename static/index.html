Choose a capture mode
Video provides continuous road coverage. Periodic stills collect full-sensor photos at an interval but leave gaps. Road A/B experiment compares two equal-nominal-exposure shutter/gain settings while driving. Stationary still sweep tests an ordered grid only when the camera and scene are stationary.

        
Run a Road A/B experiment
  1. Choose reference shutter and gain. CameraDeck calculates B gain from B shutter so shutter × gain remains equal.
  2. Draw the analysis area over road surface in the live preview, or enter percentages. Exclude sky and bonnet, then confirm the area.
  3. Use eight blocks as a starting point. CameraDeck alternates randomized ABBA/BAAB blocks and waits for measured controls to settle.
The ROI selects offline analysis only; full lossless luminance frames and request metadata are saved. An unfinished block may be discarded when stopping, while completed blocks remain.

        
Analyze an experiment
Download and extract the experiment ZIP on a workstation containing CameraDeck, then run:
uv run python -m quality RUN_DIR --output REPORT_DIR
The analyzer writes report.json, pairs.csv, and contact-sheet.jpg. It can report A preferred, B preferred, trade-off, or insufficient evidence. It rejects metadata, exposure, timing, and scene-drift faults and never applies a winner automatically.

        
Photos, video, and stationary sweeps
Video snapshots use video resolution without stopping recording. A normal photo uses the full sensor and briefly pauses preview. Periodic stills take the first photo immediately; slow captures extend the interval rather than queuing missed photos. Stationary sweeps settle before every photo and restore previous settings afterward.

        
Understand camera controls
Shorter shutter reduces motion blur but gathers less light. Higher gain brightens the result while increasing noise. Frame rate controls sampling, not shutter blur. The Short AE preference is camera tuning, not a fixed shutter cap. Sharpness-grid values measure local detail and can rise with noise; compare like scenes and exposures.

        
Library and storage
Captures remain local until explicitly downloaded or uploaded. Metadata is available beside every capture. Delete is permanent. CameraDeck preserves a 256 MiB storage reserve and does not automatically loop-delete old footage.

        
Connection and safety
All browsers share one Pi camera. Recording and capture sequences continue when a browser leaves Live view or disconnects. If disconnected, assume a run may still be active until status returns. Settings are session-local. Use a passenger to operate CameraDeck and never adjust it while driving.
